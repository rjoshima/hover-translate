# Hover Translate

英文の上で0.7秒止めると、日本語の吹き出しを表示する個人用Macアプリ。OpenRouterの手持ちのAPIキーを使います。

**試作段階です。ビルドとローカルチェックは確認できますが、実際のAPI翻訳・Codex上のホバー動作は、キー入力とアクセシビリティ許可後に確認が必要です。**

## 使い方

1. `scripts/build.sh` で `dist/Hover Translate.app` を作成し、Applicationsフォルダへコピーして起動します。
2. アプリ内でOpenRouter APIキーを入力して保存し、「接続テスト」で日本語訳を確認します。チャットやソースにキーを書く必要はありません。
3. 「Macのアクセス設定を開く」からHover Translateのアクセシビリティを許可します。
4. 「ホバー翻訳を開始」を押してCodexに戻り、英文の上で少し止めます。選択済みの文章が同じ要素にあれば、その選択を優先します。
5. メニューバーから停止・設定変更・終了できます。起動直後は常に停止しています。

初期の対象アプリはCodexとClaude（Claude Codeのデスクトップ画面を含む）。既存設定にもClaudeを一度だけ追加します。設定の「変更」で起動中の別アプリも選べます。

キーを保存すると入力欄は隠れます。次回起動時は設定ウィンドウを自動表示せず、メニューバーから使えます。変更するときだけ「設定を開く」→キーの「変更」を押します。翻訳の開始は引き続き明示操作です。

## 費用とデータ

- モデル：`openai/gpt-4.1-nano`。2026-09-27確認の料金は入力100万トークンあたり$0.10、出力$0.40。
- 入力300・出力300トークンなら1回$0.00015、$10で約66,666回。文字量・料金改定で変わります。入力には翻訳指示も含みます。
- 原文は最大1,800文字、出力は最大1,200トークン。1日500リクエストまで。失敗・キャンセルも回数に含め、自動再試行はしません。
- 単価上限をOpenRouterのprovider設定にも指定。高い提供元への切り替えを防ぎます。同じモデルの提供元間の切り替えは許可します。
- 同一文はメモリ内の64件キャッシュを使います。停止・終了すると破棄します。回数上限はこのアプリ内の制限であり、OpenRouterアカウント全体の金額上限ではありません。
- カーソル下の英文をOpenRouterとモデル提供元へ送信します。`data_collection: deny` と `zdr: true` を指定し、条件に合う提供元がなければ送信を失敗させます。OpenRouter側のアカウント設定・ポリシーは別途適用されます。
- APIキーはチャットではなくアプリのSecureFieldに入力し、**このMacのキーチェーンにのみ保存**。iCloud同期は未対応で、同じApple Accountへのサインインだけでは別のMacに共有されません。同期にはAppleの署名・プロビジョニングによるdata protection keychainへのアクセス設定が必要で、現在のad-hoc署名にはありません。現在はMacごとに初回だけ保存してください。
- 認識できるAPIキー・トークン・秘密鍵・パスワード代入を含む文字列は送信を拒否します。これは完全な機密情報検出ではなく、すべての個人情報・企業情報を見分けるものではありません。対象アプリでホバーした英文は外部送信されるため、必要に応じてメニューバーで停止してください。
- HTTPリダイレクトは追従せず、キーや原文を別の宛先へ転送しません。
- 原文・訳をディスクに保存せず、テレメトリーもありません。設定と日別の回数だけUserDefaultsに保存します。
- スクリーンショット、画面録画、クリップボード、ブラウザ履歴、文書全体の走査は使いません。アクセシビリティの文字を提供しない場所では動作しません。

OpenRouterでは、このアプリ専用の利用上限付きキーを推奨します。既存キーの上限をアプリが勝手に変更することはありません。

料金：[OpenRouter GPT-4.1 nano](https://openrouter.ai/openai/gpt-4.1-nano)

## 開発

macOS 26 / Swift 6.2で開発。外部ライブラリ・サーバー・パッケージのダウンロードは不要。

```sh
./scripts/check.sh
./scripts/check-keychain.sh  # 一意のテスト領域だけで、ダミー値の保存・更新・削除を検証
./scripts/build.sh
```

`Package.swift` は通常のSwiftPM環境でも開けます。このMacではSwiftPM自体の共有ライブラリが欠落していたため、スクリプトは`swiftc`を直接使います。古いCommand Line Toolsの重複module mapはビルド時だけのVFS overlayで回避し、システムファイルは変更しません。

成果物はHardened Runtimeを有効にしたローカルのad-hoc署名です。再ビルド後はmacOSがキーチェーンへのアクセスを再確認することがあります。Apple公証済みの一般配布アプリではありません。外部へ配布する際は別途Developer ID署名・公証が必要です。

### 手動確認

- キー保存→接続テストで自然な日本語になる。
- Codex・Claudeの英文段落に停止→翻訳が近くに出る。
- カーソル移動・アプリ切り替え・停止後に、古い翻訳が遅れて出ない。
- 日本語・パスワード欄・対象外アプリを翻訳しない。
- 同じ英文はAPIを再呼び出ししない。通信エラーはキー・原文をログ出力しない。
- 外部ディスプレイの上下左右の配置でもポップアップが画面内に出る。

自動チェック：ホバー待機・再発火制御、英文判定、文字数上限、キャッシュ破棄、API宛先・送信形式・単価設定、失敗レスポンス・訳の途中切れ。

## 別のMacで使う

この非公開リポジトリにアクセスできるGitHubアカウントでクローンし、上記ビルド手順を実行します。MacごとにAPIキーの初回保存とアクセシビリティ許可が必要です。キーそのものはGit・設定ファイル・iCloud Driveへコピーしません。

現在、実APIの成功、Codex/Claudeのホバー動作、別Macでの実行は未確認です。ローカルのキーチェーン検証は合成データのみで行います。
